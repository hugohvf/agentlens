# Org Scan Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow users to paste a GitHub org URL into the Compare tab to automatically scan all public repos, surface those with agent configs (with pagination, sorting, and multi-select), and add selected ones to the comparison.

**Architecture:** All code lives in `agentlens.html` (single-file app). We add `parseOrgUrl()`, `ORG_SCAN_STATE`, `fetchOrgRepos()`, `scanOrg()`, and a dedicated `#org-scan-panel` HTML section in the Compare tab. Batch scanning (10 repos/batch, 600ms delay) keeps GitHub's unauthenticated rate limit safe. The compare item limit is raised from 6 → 20.

**Tech Stack:** Vanilla JS, Chart.js (already loaded), GitHub REST API (`api.github.com/orgs/{org}/repos`), raw.githubusercontent.com for file content (already used), no new dependencies.

- [ ] **Step 1: Add `parseOrgUrl()` near `parseRepoUrl()`**

  After `parseRepoUrl` (~line 955):
  ```javascript
  function parseOrgUrl(u){u=u.trim().replace(/[?#].*$/,'').replace(/\/+$/,'');const m=u.match(/^https?:\/\/github\.com\/([^/]+)$/);return m?{org:m[1]}:null}
  ```

  Note: `parseRepoUrl` already requires TWO path segments (`/owner/repo`). `parseOrgUrl` only matches exactly ONE segment — so `github.com/alura-cursos` matches as org, `github.com/alura-cursos/some-repo` does not. Query strings and hash fragments (e.g., `?tab=repositories`, `#repositories`) are stripped before matching to handle URLs copied from the browser address bar.

## Task 7: Add `fetchOrgRepos()` function

**Files:**
- Modify: `agentlens.html` — add new function in the COMPARE REPOS section (~line 1427)

- [ ] **Step 1: Add `fetchOrgRepos()` after `COMPARE_STATE` + `ORG_SCAN_STATE` block**

  ```javascript
  async function fetchOrgRepos(org){
    const repos=[];
    let page=1;
    while(true){
      let r;
      try{
        r=await fetch(`https://api.github.com/orgs/${org}/repos?per_page=100&page=${page}&type=public&sort=created&direction=desc`);
      }catch(e){return{error:'network'}}
      if(r.status===404)return{error:'notfound'};
      if(r.status===403||r.status===429)return{error:'ratelimit'};
      if(!r.ok)return{error:'network'};
      const data=await r.json();
      if(!Array.isArray(data)||!data.length)break;
      repos.push(...data);
      if(data.length<100)break;
      page++;
      await new Promise(res=>setTimeout(res,300));
    }
    return{repos};
  }
  ```

  function sortedOrgConfigured(){
    const arr=[...ORG_SCAN_STATE.configured];
    const d=ORG_SCAN_STATE.sortDir;
    if(ORG_SCAN_STATE.sortBy==='tokens')arr.sort((a,b)=>d*(( b.totalContextTokens||0)-(a.totalContextTokens||0)));
    else if(ORG_SCAN_STATE.sortBy==='stars')arr.sort((a,b)=>d*((b.stars||0)-(a.stars||0)));
    else if(ORG_SCAN_STATE.sortBy==='date')arr.sort((a,b)=>d*(new Date(b.createdAt)-new Date(a.createdAt)));
    else arr.sort((a,b)=>d*a.name.localeCompare(b.name));
    return arr;
  }

## Task 11: Add `scanOrg()` — the main orchestrator

**Files:**
- Modify: `agentlens.html` — add after `downloadOrgReport()`

- [ ] **Step 1: Add `scanOrg()`**

  ```javascript
  const ORG_SCAN_BATCH_SIZE=10;
  const ORG_SCAN_BATCH_DELAY=600;

  async function scanOrg(org){
    // Reset state — also sets scanning:true which acts as the "generation" token
    Object.assign(ORG_SCAN_STATE,{
      org,totalRepos:0,scannedCount:0,scanning:true,done:false,
      repos:[],configured:[],unconfigured:[],
      selected:new Set(),page:0,sortBy:'tokens',sortDir:-1,unconfiguredVisible:false,
    });
    // Capture generation: if user triggers a new org scan while this one runs,
    // scanning will be reset to true for the new org — stale batch callbacks
    // will see ORG_SCAN_STATE.org !== org and bail out.
    const thisOrg=org;

    showOrgPanel();
    renderOrgProgress('fetching');
    clearCmpStatus();

    const result=await fetchOrgRepos(org);
    if(ORG_SCAN_STATE.org!==thisOrg)return; // aborted by new scan
    if(result.error){renderOrgError(result.error);return}

    const allRepos=result.repos;
    ORG_SCAN_STATE.totalRepos=allRepos.length;
    renderOrgProgress('scanning');

    for(let i=0;i<allRepos.length;i+=ORG_SCAN_BATCH_SIZE){
      if(ORG_SCAN_STATE.org!==thisOrg)return; // aborted by new scan
      const batch=allRepos.slice(i,i+ORG_SCAN_BATCH_SIZE);
      await Promise.all(batch.map(async repo=>{
        let scanData;
        try{
          scanData=await analyzeRepoData(repo.owner.login,repo.name);
        }catch(e){
          scanData={ok:false,error:'network'};
        }
        if(ORG_SCAN_STATE.org!==thisOrg)return; // aborted
        const entry={
          fullName:repo.full_name,
          name:repo.name,
          org:repo.owner.login,
          description:repo.description||'',
          stars:repo.stargazers_count||0,
          forks:repo.forks_count||0,
          language:repo.language||'',
          createdAt:repo.created_at||'',
          updatedAt:repo.updated_at||'',
          ...scanData,
        };
        ORG_SCAN_STATE.repos.push(entry);
        if(scanData.ok&&!scanData.noFiles){
          ORG_SCAN_STATE.configured.push(entry);
        }else{
          ORG_SCAN_STATE.unconfigured.push(entry);
        }
        ORG_SCAN_STATE.scannedCount++;
        // Note: renderOrgProgress is NOT called here — called once per batch below
      }));
      // Render progress once per batch, not once per repo (avoids 10x DOM updates per batch)
      renderOrgProgress('scanning');
      if(i+ORG_SCAN_BATCH_SIZE<allRepos.length){
        await new Promise(res=>setTimeout(res,ORG_SCAN_BATCH_DELAY));
      }
    }

    if(ORG_SCAN_STATE.org!==thisOrg)return; // aborted
    ORG_SCAN_STATE.scanning=false;
    ORG_SCAN_STATE.done=true;
    renderOrgResults();
  }
  ```
